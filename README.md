# Todo App - MERN Stack

A fully functional Todo application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. This app allows users to manage tasks efficiently with features like creating, updating, deleting, and filtering todos.

## Features

- **Task Management:**
  - Add, edit, and delete tasks.
  - Set task priorities and categories.

- **Filtering and Sorting:**
  - Filter tasks by priority or category.
  - Sort tasks by due date or other criteria.

- **User-Friendly Interface:**
  - Intuitive design with React.js and optional TailwindCSS.
  - Responsive and mobile-friendly.

## Technologies Used

- **Frontend:**
  - React.js
  - SCSS 

- **Backend:**
  - Node.js
  - Express.js

- **Database:**
  - MongoDB
